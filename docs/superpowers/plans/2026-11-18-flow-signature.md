## Task 1 — `v2_flow_signature` module + reference constants

New `map_creation/v2_flow_signature.py`:

```python
BANDS = ((.1,), (.2,), (.4,), (.6,), (math.inf,))  # upper bounds
def band_index(gap): ...
def signature(notes): ...
def signature_distance(sig, reference=None): ...
def specific_counts(notes): ...  # inner_y1_fast, top_horizontal_fast, ...
def signature_report(notes): ...  # {"signature":…,"distance":…,"specific":…}
```

- `signature` returns per-gap-band Counters for lane type
  (same/adjacent/wide by |Δx|), Δy ∈ -2..2, `_step_distance` clamped ≤4,
  outer-pair flag; same-x run-length histogram capped at 8; 12-cell
  occupancy per hand; ABAB-4 eligible/alternating windows (same
  definitions as the derivation script: singleton non-dot groups,
  gap ∈ (eps, .4]).
- `signature_distance` = weighted total variation per distribution vs the
  pooled reference signature, weights: lane-hist 3, step-hist 2, dy-hist 1,
  run-length 2, occupancy 1, abab 1 (document formula in docstring).
- `map_creation/reference_signature.json`: pooled constants, generated by
  the derivation script's `reference_signatures` (sum the seven).
- `specific_counts`: `inner_y1_fast`, `inner_y1_terminal`,
  `inner_y2_fast`, `top_horizontal_fast`, `top_horizontal_terminal`,
  `mid_horizontal_fast`, `inner_top_horizontal_fast`, plus `notes`.
- Tests: hand-built note lists → exact expected counters/histograms;
  distance zero for the reference constants themselves; band boundaries at
  .1/.2/.4/.6; dot/stack pairs skipped.

## Task 2 — Unified specific rules in `style_cost`

- `style_cost` → 5-tuple `(center, horizontal, boundary, upper,
  top_horizontal)`:
  - `center` = 12 iff `note["x"] in (1,2) and note["y"] == 1` and
    `following` is not None and `following["time"] - note["time"] <= .4 + _TOL`.
    Remove `_terminal_accent`/`fastest` gating for this component
    (following-gap exemption only). `_terminal_accent` stays for other
    uses.
  - `top_horizontal` = 6 iff `note["y"] == 2 and note["d"] in (2,3)` and
    `following` is not None and following gap ≤ .4 + _TOL.
- `_check_chunk` return tuple: `(*agg5, repetition, displacement,
  deviation)` — repetition is now index 5; update `lanes._attempt`
  (`key[4]`→`key[5]`, `key[:4]`→`key[:5]`, rank `(key[5], *key, order)`)
  and any other arity-sensitive code.
- Tests first: centered note followed at .3s penalized, followed at .5s
  exempt; top-row horizontal followed fast penalized, slow exempt, mid-row
  y=1 unaffected; tuple arity reflected in `_check_chunk` keys; existing
  phrase/lateral behavior unchanged except new components count.

## Task 3 — Gap-band speed cap

- `tools/config/config.py`: `v2_speed_cap_gap_factors = (4.0, 3.5, 1.8,
  1.0, 0.7)` matching bands `(<.1, <.2, <=.4, <=.6, >.6)`.
- `_speed_ok` in `v2_forward_patterns.py`: per edge compute
  `dt = note["time"] - previous_time` (for successor edges, dt = succ−last);
  bound = `max(cap(note) * band_factor(dt), incumbent)`; unchanged when the
  config tuple is empty/None (legacy flat behavior for safety).
- Keep `_default_cap`, ramp, SpeedGroups, reach pass unchanged.
- Tests: fixture where a candidate exceeds flat cap but fits the
  <.2s band → accepted; >.6s edge at 1.2× flat cap → rejected; per-band
  boundary at .2s exact; `v2_speed_cap_gap_factors=()` restores flat cap.

## Task 5 — Reach tie-break + addition checks

- `_reach_pass`: after computing the feasible pool (existing code), among
  candidates whose cost tuple is within `_TOL` of the best, choose the one
  minimizing `(new_triple, inner_middle_fast, displacement)`,
  `new_triple = lanes.repetition_cost(context-ish, [dict(note, x=tx,
  y=ty)])`, `inner_middle_fast = tx in (1,2) and ty == 1 and next same-hand
  gap ≤ .4`.
- `flow.accepts_added(context, note)`: returns False when placing the
  note creates a touched same-x triple (repetition_cost) or
  inner-middle-fast; wire into `validate_expansions` (v2_forward_expansion)
  and `apply_note_emphasis` (v2_note_emphasis) acceptance, and the gap
  fill path used in forward mode; count skipped in reports.
- Tests: reach chooses off-lane position when cost-equal; added note into
  same-x run rejected; added note at inner-middle with fast follower
  rejected, allowed when terminal; counts reported.
